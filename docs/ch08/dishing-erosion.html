Model (illustrative): trench depth T0 = 300 nm drawn as 110 units. Dishing = 110 nm x t, erosion = 125 nm x t, small extra dishing in narrow lines = 16 nm x t, where t is the over-polish slider. Line resistance R = ρL/(W·T), so with width and length fixed, R/R0 = T0/T. Soft copper polishing faster than hard dielectric, and dense areas polishing differently from sparse ones, are the causes given in the chapter. Dummy fill (chapter) evens out pattern density to reduce this.
