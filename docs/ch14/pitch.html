Reference start: CPP 48 nm and MMP 30 nm (illustrative, in the range the chapter describes for a 3 nm-generation chip, where gates sit roughly forty to fifty nanometers apart). Relative density ~ (48 x 30) / (CPP x MMP) is an idealization: real density also depends on cell layout (DTCO), SRAM cell area and more. Node names such as "3 nm" are generation labels, not these dimensions.
