Same defects, different die size

Both wafers have exactly the same defects. A die fails if at least one defect lands on it. Change the die sizes and the defect density.

Illustrative: 300 mm wafer, square dies, D0 in defects per cm², no edge exclusion. Only dies fully inside the wafer are counted. The "counted" number is this one random sample; the Poisson formula is the average you would expect over many wafers, so they differ a little (more on small samples).
