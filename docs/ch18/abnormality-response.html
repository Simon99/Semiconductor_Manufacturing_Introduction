Inject an abnormality, see which lots get held

Pick a tool, say when the problem really began and when it was noticed. The fab does not know the true start, so it holds everything since the last known good check. All lots, tools and times are illustrative.

Inject abnormality at tool

Held = lots that ran on the tool between the last passed monitor wafer and the moment the problem was caught (README: scope starts from the last known good point). Over-held = lots held as a precaution that turned out clean. Disposition options follow the chapter's table: release, rework, scrap, conditional release; real cases with large or uncertain impact go to a material review board.
