Illustrative model: 2.5D link = 1024 wires (the width of one HBM interface); board link = 64 wires (a typical memory channel); both at an assumed 4 Gb/s per wire. Energy per bit is taken as proportional to wire length, because a longer wire has more capacitance to charge.
