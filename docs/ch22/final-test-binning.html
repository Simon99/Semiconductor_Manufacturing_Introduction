Simplified model (all numbers illustrative, not real device data)

  • Each simulated chip has a max speed Fmax25 at 25 °C drawn from a bell curve (mean 3.0, spread 0.2, in made-up GHz units, fixed random seed).
  • Hot is slower here: Fmax(T) = Fmax25 × (1 − 0.0005 × (T − 25)). Real chips differ by design and process; this is a simplification.
  • Leakage power grows with temperature: leak(T) = leak25 × 2^((T−25)/30); total power P = 10 W + leak(T). Faster chips tend to leak more (correlated draw). Limit: P ≤ 20 W.
  • Bin rule: FAST if Fmax(T) ≥ 3.1 and within the power limit; SLOW if Fmax(T) ≥ 2.7; otherwise FAIL. Binning is done at the test temperature chosen.
  • 3% of chips carry an assembly defect (fail at any temperature); 3% are temperature-sensitive and fail when the test is more than 60 °C away from 25 °C. Both are made-up rates.
  • SLT: 3% of chips that pass the tester still fail when running real software. Made-up rate, only counted when SLT is on.
  • The fail count shows the first failing check in this order: defect, temperature-sensitive, power, speed.
