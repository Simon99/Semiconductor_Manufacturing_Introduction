碟陷（Dishing）與侵蝕（Erosion）：拖曳過度研磨時間（Over-polish time）

CMP 後一層銅導線（Copper line）的剖面。所有深度皆為示意，不是實測數據。

85%
碟陷深度（Dishing depth，寬導線中央）
侵蝕深度（Erosion depth，密集區域相對周圍）
寬導線：中央剩餘厚度
密集導線：剩餘厚度
寬導線：局部電阻（Resistance）R/R0
密集導線：電阻 R/R0

模型（示意）：溝槽深度（Trench depth）T0 = 300 nm，圖中以 110 單位繪製。碟陷 = 110 nm x t，侵蝕 = 125 nm x t，窄導線額外的少量凹陷 = 16 nm x t，其中 t 為過度研磨滑桿的值。導線電阻 R = ρL/(W·T)，因此在寬度與長度固定時，R/R0 = T0/T。軟的銅比硬的介電層磨得快，以及密集區域與稀疏區域的研磨情形不同，是章節中說明的成因。虛擬填充（Dummy Fill，見章節）可讓圖形密度更平均，減輕這個問題。
