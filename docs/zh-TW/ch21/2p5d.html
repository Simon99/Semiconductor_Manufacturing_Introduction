2.5D 封裝（2.5D packaging）：為什麼要把晶片（Chip）放在中介層（Interposer）上？

處理器（Processor）與 HBM 記憶體堆疊（High Bandwidth Memory stack）並排放置。切換它們的連接方式，並拖曳調整距離。

橘色圓點 = 資料位元（Bit），兩種模式下移動速度相同圖中畫出的導線（Wires）只是示意取樣，實際數量見讀數
連線的導線數（Wire count，示意）
頻寬（Bandwidth，示意，每條導線速度相同）
導線長度（Wire length）
每位元能耗（Energy per bit，相對 1 mm 連線）

示意模型：2.5D 連線 = 1024 條導線，即一組 HBM 介面（Interface）的寬度；電路板連線 = 64 條導線，即典型的記憶體通道（Memory channel）；兩者皆假設每條導線 4 Gb/s。每位元能耗視為與導線長度成正比，因為導線越長，要充電的電容（Capacitance）越大。
