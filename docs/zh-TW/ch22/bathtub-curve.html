浴缸曲線與預燒

晶片生命週期中的失效率，以及工廠預燒能篩除與無法篩除的部分。所有模型數值皆為示意。

-於工廠篩除
-出貨品：第 0 小時失效率（FIT）
-出貨品：第 1000 小時失效率（FIT）

模型（示意）：危害率（hazard） h(t) = hearly + hrandom + hwear；各韋伯（Weibull）危害率為 (β/η)(t/η)β−1。早期：β=0.5、η=2,000 小時、權重 0.02（體質弱的子群體）。隨機：β=1、固定 1,000 FIT。老化期：β=4、η=60,000 小時。在應力下預燒 b 小時，等於 AF×b 等效現場小時（假設 AF=10）。篩除比例 = 1−exp(−H(AF·b))。出貨品在現場第 τ 小時的危害率為 h(AF·b+τ)：同一條曲線，起點向右移。FIT = 每 109 元件小時的失效次數。第 0 小時以 1 小時計算，以避開 β<1 的奇異點。本圖為標準可靠度示意圖，並非任何產品的實測資料。
