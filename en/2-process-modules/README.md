# Part 2: Process Modules

A fab runs hundreds to more than a thousand process steps, but most of them are combinations of a few basic process modules. This part introduces each module in turn: what it does, which tools it uses, which numbers matter, and what typically goes wrong.

In real production, the wafer cycles through these modules again and again: deposit a film, pattern it with lithography, etch or implant, clean, measure, and then build the next layer. The book starts with lithography because it is the heart of the loop.
