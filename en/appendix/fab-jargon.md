# Appendix B: Fab Jargon

Every fab has its own everyday vocabulary, such as "This lot's Q-time is almost up, run it first." Newcomers hearing it for the first time are often lost.

This appendix lists expressions commonly heard in fabs, with example sentences. The second column shows how each one is usually said in Taiwanese fabs, where people mix Chinese with English terms; this is useful if you work with Taiwanese colleagues. Habits differ from company to company, so these are the most widely used forms. For formal definitions, see [Appendix A: Glossary](glossary.md).

---

## Wafers and lots

| Expression | In Taiwanese fabs | Meaning | Example |
|---|---|---|---|
| Lot | Lot | A group of wafers, up to 25 | "This lot ships today." |
| Wafer start | 投片 | Releasing blank wafers into production | "Wafer starts are up this month." |
| Fab out | Fab Out | Wafers finishing the front end and leaving the fab | "This lot should fab out next week." |
| Hot lot | Hot Lot | A lot with production priority | "This is a hot lot. Run it as soon as it arrives." |
| Split | Split | Dividing a lot into groups that get different conditions | "Split this lot into three conditions." |
| Merge | Merge | Combining split wafers back into one lot | "Merge them back once the experiment is done." |
| Bank | Bank | Parking wafers at a step to wait | "Bank this lot before the metal layers." |
| WIP | WIP | Wafers still on the line | "Too much WIP is piling up in front of photo." |
| Moves | Move | The number of process steps completed in a period, used to measure output | "Did the fab hit its move target today?" |
| Monitor wafer | 控片 | A test wafer used to check the condition of a tool | "Run a monitor first to check the film thickness." |
| Dummy wafer | 擋片 | A wafer used to fill empty slots or condition a tool | "Remember to fill the empty furnace slots with dummies." |
| Broken wafer | 破片 | A cracked or broken wafer | "The robot broke a wafer while picking it up." |

## Tools

| Expression | In Taiwanese fabs | Meaning | Example |
|---|---|---|---|
| Recipe | Recipe | The set of parameters a tool uses to run a process | "There's a new version of the recipe for this step." |
| PM | PM | Scheduled preventive maintenance | "This tool has PM this afternoon." |
| Down | Down（Down 機） | A tool that is broken or out of service | "The etcher is down. EE has been notified." |
| Back up | 復機 | A tool repaired and back in production | "This tool should be back up tonight." |
| Qual | Qual | The check that confirms a tool is fit for production | "After PM it has to pass qual before it can run product." |
| Seasoning | Seasoning | Running dummy wafers after maintenance to stabilize the chamber | "Season it with twenty dummies first." |
| Chamber | Chamber | The part of a tool where processing actually happens | "This wafer ran in chamber B." |
| Idle | Idle | A tool with no wafers to run | "This tool has been idle for a long time." |
| Dedication | 綁機 | Restricting wafers to a specific tool | "This layer has to be dedicated to the same scanner." |
| Load port | Load Port | The platform at the front of a tool where the wafer carrier goes | "The load port can't read the FOUP ID." |

## Systems and flow

| Expression | In Taiwanese fabs | Meaning | Example |
|---|---|---|---|
| Track-in | 進站 | Recording in the system that processing has started | "Load the lot and track it in." |
| Track-out | 出站 | Recording in the system that processing is finished | "The tool's done. Remember to track out." |
| Hold | Hold | Stopping production of a lot or a tool | "This lot is on hold because its Q-time expired." |
| Release | Release | Lifting a hold so production can continue | "Engineering says it's fine. You can release it." |
| Q-time | Q-Time | The time allowed to wait between two steps | "This lot's Q-time is almost up. Run it first." |
| Dispatching | 派工 | Deciding which lot a tool runs next | "Dispatching put this lot at the top of the list." |
| Run product | 跑貨 | Processing product wafers on a tool | "Can this tool run product yet?" |
| Records don't match | 帳實不符 | The system records do not match what is physically happening | "The system says it tracked out, but the wafers are still in the tool. The records don't match." |

## Quality and abnormalities

| Expression | In Taiwanese fabs | Meaning | Example |
|---|---|---|---|
| OOC | OOC | Data outside the control limits | "This point is OOC. Follow the OCAP." |
| OOS | OOS | Data outside the specification | "Film thickness is OOS. We need an MRB." |
| Rework | Rework | Doing a step again, mainly in lithography | "ADI failed, so it needs rework." |
| Scrap | Scrap | Taking wafers out of production for good | "This wafer is broken. It can only be scrapped." |
| Excursion | Excursion | A sudden quality problem | "Yesterday's defect excursion hit three lots." |
| MRB | MRB | A cross-functional meeting that decides what to do with nonconforming material | "This lot needs an MRB decision." |
| Map | Map | Wafer map | "Check this wafer's map for scratches." |
| Particles | Particle | Tiny particles on the wafer | "The particle count on this wafer is over the limit." |

## Areas and people

| Expression | In Taiwanese fabs | Meaning | Example |
|---|---|---|---|
| Photo | 黃光 ("yellow light") | The lithography area, named after its yellow lighting | "This lot is stuck in photo." |
| Diffusion | 爐管 | The area of high-temperature batch tools for oxidation and annealing | "Furnace batching is slow today." |
| Wets | Wet | The wet cleaning and wet etching area | "Send it to wets for a clean first." |
| PE, EE, PIE, YE | PE、EE、PIE、YE | Process, equipment, process integration and yield engineers | "Let the PIE make the call on this one." |
| Handover | 交接 | Passing on the status of tools and wafers at shift change | "At handover, make it clear this tool is still being watched." |
