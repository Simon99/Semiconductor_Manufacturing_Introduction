# Appendix A: Glossary

This glossary lists the main terms used in the book, in alphabetical order. The "Chapter" column gives the chapters where each term mainly appears or is explained. The Traditional Chinese column gives the term used in Taiwanese fabs, which is useful if you work with Chinese-speaking colleagues.

The glossary is also the **single reference** for terminology across the book: when writing or translating, follow the terms in this table. To add a language, add a column for it. See [TRANSLATIONS.md](../../TRANSLATIONS.md).

For how these words are actually used on the fab floor, see [Appendix B: Fab Jargon](fab-jargon.md).
