# 第 0 章　半導体製造の全体像：チップの一生

> 📍 **ウェーハの現在地**
>
> - 前の工程：まだ出発していない
> - **この章：チップが設計から出荷までたどる旅を、上空から見渡す**
> - 次の工程：ファブの中に入り、どう動いているかを見る

---

## 1 枚のウェーハの旅

スマートフォン、パソコン、自動車、家電製品には、どれもチップが入っています。爪ほどの大きさのチップに、数十億から数千億個のトランジスタが載ることもあり、そのすべてが薄いシリコンウェーハの上で「作られて」います。

半導体製造は、人類が行う製造の中でも最も複雑なものの一つです。1 枚のウェーハは数百から千を超える工程を数か月かけて通り、ようやく使えるチップになります。この本は **1 枚のウェーハ** を、何も描かれていないシリコンの状態から、工程を一つずつ追いかけていきます。

この章ではまず地図を渡します。以降の各章の冒頭にある「📍 ウェーハの現在地」が、ウェーハがいま地図のどこにいるのかを教えてくれます。

## 誰が何をするのか：半導体産業の分業

チップが形になるまでには、ふつう何種類かの会社が分担して関わります。

| 役割 | 何をするか |
|---|---|
| ファブレス（IC 設計会社） | チップの回路を設計するが、自社の工場は持たない |
| ファウンドリ（受託製造） | 設計会社から委託を受け、ウェーハ上に回路を製造する |
| IDM（垂直統合型メーカー） | 設計から製造、販売までを自社で行う |
| OSAT（後工程受託） | ウェーハを個々のチップに切り分け、パッケージングとテストを行う |
| 装置・材料メーカー | 製造に使う装置、薬液、ガス、ウェーハなどを供給する |

> [!NOTE]
> **📖 用語｜ファウンドリ（晶圓代工）**
>
> - **定義**：自社製品のチップは設計せず、顧客のためにチップを製造するビジネスモデル。
> - **現場での使い方**：「この品種はお客さんの投入分です」。ファウンドリでは、顧客ごとの設計を一つの「品種（製品）」として扱うのが一般的。
> - **関連用語**：ファブレス、IDM、OSAT
> - **よくある混同**：IDM もファウンドリも工場を持っている。違いは、IDM は主に自社設計の製品を作り、ファウンドリは他社の製品を作る点にある。

## 旅の地図

**設計 → マスク製作 → ウェーハ投入 → 前工程 → ウェーハテスト → パッケージング → 最終テスト → 出荷**

| 段階 | 何が起きるか | 本書の章 |
|---|---|---|
| 設計 | エンジニアがソフトウェアで回路を設計し、各層のパターンに変換する | [第 14 章](../../3-integration/14-process-nodes/README.md)で少し触れる |
| マスク製作 | 各層のパターンを 1 枚ずつのマスクにする | [第 4 章](../../2-process-modules/04-lithography/README.md) |
| ウェーハ投入 | ベアウェーハが工場に入り、生産が正式に始まる | [第 3 章](../../1-fundamentals/03-sand-to-wafer/README.md) |
| 前工程 | ウェーハ上にトランジスタと金属配線を 1 層ずつ作る | [第 4～18 章](../../2-process-modules/README.md) |
| ウェーハテスト | ウェーハ上のチップ一つひとつの良否を調べる | [第 19 章](../../5-backend/19-wafer-test/README.md) |
| パッケージング | ウェーハを切り分け、良品のチップをパッケージに収める | [第 20、21 章](../../5-backend/20-packaging/README.md) |
| 最終テスト | パッケージ後にもう一度テストし、長年使えることを確かめる | [第 22 章](../../5-backend/22-final-test-and-reliability/README.md) |

## 前工程と後工程

半導体製造でいちばんよく使われる分け方は、**前工程** と **後工程** です。

- **前工程**：ファブの中で、ウェーハ上に回路を 1 層ずつ作る。本書の第 2 部から第 4 部のテーマで、最も時間がかかる部分。ふつう 2～3 か月、またはそれ以上かかる。
- **後工程**：完成したウェーハをテストし、切り分け、回路基板にはんだ付けできるチップにパッケージングする。

> [!NOTE]
> **📖 用語｜前工程と後工程（前段與後段）**
>
> - **定義**：前工程はウェーハ製造、後工程はパッケージングとテストを指す。
> - **現場での使い方**：「彼は前工程でプロセスを担当している」「このチップは後工程で止まっている」。
> - **関連用語**：FEOL、BEOL、組立・テスト
> - **よくある混同**：「前工程・後工程」には二つの意味がある。ウェーハ製造とパッケージング・テストを分ける意味のほか、ファブの中でもトランジスタを作る工程を FEOL、金属配線を作る工程を BEOL と呼ぶ。[第 11 章](../../3-integration/11-cmos-process-flow/README.md)を参照。どちらの意味かは文脈で判断する。

## ウェーハ、ダイ、チップ

1 枚のウェーハには、同じ回路がたくさん整然と並んでいます。一つひとつの回路を **ダイ** と呼びます。ダイとダイの間には細い **スクライブライン** があり、最後にこのラインに沿ってウェーハを切り分け、ダイをパッケージに収めると、ふだん目にする **チップ** になります。

300 mm ウェーハ 1 枚からは、ダイの大きさによって数十個から数万個のダイが取れます。

## 工場の三つの基本単位

ファブでは、次の三つの言葉をほぼ毎日耳にします。

| 用語 | 意味 | たとえ |
|---|---|---|
| ロット（Lot） | 一緒に移動し、一緒に処理されるウェーハのまとまり。最大 25 枚で、一つのキャリアに入る | 卵のパック |
| ルート（Route） | 製品が最初から最後までに通るすべての工程と、その順番 | 料理の手順書 |
| レシピ（Recipe） | ある工程で装置が使う条件。温度、時間、ガス流量など | オーブンの温度と時間の設定 |

## 何度も繰り返すループ

前工程には数百から千を超える工程がありますが、その大部分は同じ動作の繰り返しです。

**材料を成膜する → リソグラフィでパターンを作る → エッチングまたはイオン注入 → 洗浄 → 計測**

ビルを建てるのと同じで、各階が似た作業を経てから、その上に次の階を建てていきます。第 2 部でこれらの動作を一つずつ紹介し、第 3 部でそれらを完全な流れにつなげます。

> [!TIP]
> **🔧 ノウハウ｜チップは「すぐ増産」できない**
>
> - **状況**：あるチップの需要が急に増えた。
> - **やり方**：チップはふつう数か月前に発注・投入され、工場も前もって生産能力を計画している。
> - **理由**：ウェーハ投入から出荷までは、前工程と後工程を合わせて 3～4 か月以上かかることが多い。しかもラインには常に、途中まで進んだ大量のウェーハが流れている。
> - **やらないとどうなる**：需要が急増したとき、すぐに投入してもチップが手に入るのは数か月後になる。半導体不足のときに供給がすぐ回復しない理由の一つがこれ。
> - **関連する章**：[第 1 章 ファブの仕組み](../../0-before-you-start/01-how-a-fab-works/README.md)

> [!TIP]
> **🔧 ノウハウ｜ウェーハは丸いのに、チップは四角い**
>
> - **状況**：ウェーハの端には、欠けたダイしか置けない。
> - **やり方**：ウェーハ上のダイの配置を決めるとき、完全なダイができるだけ多く入るようにする。
> - **理由**：ウェーハは円柱状の結晶から切り出すので丸い。一方、ダイは並べやすく切りやすいように四角形でなければならない。端の欠けたダイは製品にできない。
> - **やらないとどうなる**：無駄になる面積が増え、チップ 1 個あたりのコストが上がる。業界がより大きなウェーハへ移行してきた理由の一つでもある。
> - **関連する章**：[第 3 章 砂からウェーハへ](../../1-fundamentals/03-sand-to-wafer/README.md)

## この章のポイント

1. チップは設計、マスク、前工程、テスト、パッケージングなどの段階を経て、いくつもの役割の会社が分担して作る。
2. 前工程はウェーハ上に回路を作り、後工程はパッケージングとテストを担う。「前工程・後工程」はファブ内の FEOL と BEOL を指すこともある。
3. 1 枚のウェーハには同じダイがたくさんあり、切り分けてパッケージングするとチップになる。
4. ロット、ルート、レシピはファブで最も基本的な三つの単位。
5. 前工程は「成膜、パターン形成、エッチングまたは注入、洗浄、計測」の繰り返しである。
