# 第 2 部　プロセスモジュール

ファブには数百から千を超える工程がありますが、その大部分はいくつかの基本的な「プロセスモジュール」の組み合わせです。この部では各モジュールを順に取り上げ、何をするのか、どんな装置を使うのか、どの数値が重要か、どんな問題が起きやすいかを説明します。

実際の生産では、ウェーハはこれらのモジュールを何度も巡ります。成膜、リソグラフィ、エッチングまたはイオン注入、洗浄、計測を経て、次の層へ進みます。この本では、ループの中心であるリソグラフィから説明を始めます。

| 章 | 内容 |
|---|---|
| [第 4 章　リソグラフィ](04-lithography/README.md) | マスク、レジスト、露光装置で回路をウェーハに「印刷」する |
| [第 5 章　薄膜](05-thin-films/README.md) | 熱酸化、CVD、PVD、ALD、エピタキシー |
| [第 6 章　エッチング](06-etching/README.md) | ドライとウェット、プラズマ、選択比、終点検出 |
| [第 7 章　イオン注入と熱処理](07-ion-implantation/README.md) | ドーズ、エネルギー、アニール、熱履歴 |
| [第 8 章　CMP](08-cmp/README.md) | ウェーハを平らに磨く：スラリー、ディッシング、エロージョン、ダミーパターン |
| [第 9 章　洗浄と汚染管理](09-cleaning/README.md) | RCA 洗浄、Q タイム、クロスコンタミネーション |
| [第 10 章　メタライゼーション](10-metallization/README.md) | コンタクト、銅ダマシン、Low-k 材料 |
