# 付録 B　現場用語

ファブの日常会話には、独特の言い回しがたくさんあります。たとえば「このロット、Q タイムがもうすぐ切れるから先に流して」。業界に入ったばかりの人は、初めて聞くと戸惑うことがよくあります。

この付録では、ファブでよく聞く言い回しを例文とともにまとめます。2 列目は台湾のファブでの言い方で、中国語と英語の用語が混ざって使われています。台湾の同僚と仕事をするときに役立ちます。言い方は会社によって違うので、ここでは業界で広く使われるものを挙げています。正式な定義は[付録 A　用語集](glossary.md)を参照してください。

## ウェーハとロット

| 言い回し | 台湾のファブでの言い方 | 意味 | 例文 |
|---|---|---|---|
| ロット | Lot | ウェーハのまとまり。最大 25 枚 | 「このロットは今日出荷」 |
| 投入 | 投片 | ベアウェーハを生産に投入すること | 「今月は投入枚数が増えた」 |
| ファブアウト | Fab Out | ウェーハが前工程を終えてファブを出ること | 「このロットは来週ファブアウト予定」 |
| 特急ロット | Hot Lot | 優先して生産するロット | 「これは特急だから、着いたらすぐ流して」 |
| スプリット | Split | 1 ロットをグループに分け、条件を変えること | 「このロットは 3 条件にスプリットする」 |
| マージ | Merge | 分けたウェーハを一つのロットに戻すこと | 「実験が終わったらマージして戻す」 |
| バンク | Bank | ウェーハをある工程で止めて待たせること | 「このロットは配線工程の手前でバンクしておいて」 |
| 仕掛（WIP） | WIP | まだライン上にあるウェーハ | 「フォトの前に仕掛が溜まりすぎてる」 |
| ムーブ | Move | 一定期間に完了した工程数。出来高の指標 | 「今日の工場全体のムーブは目標に届いた？」 |
| モニターウェーハ | 控片 | 装置の状態を確認するテスト用ウェーハ | 「まずモニターを 1 枚流して膜厚を確認して」 |
| ダミーウェーハ | 擋片 | 空きスロットを埋めたり装置を慣らしたりするウェーハ | 「炉の空きスロットはダミーで埋めて」 |
| ウェーハ割れ | 破片 | ウェーハが割れること | 「ロボットが取り出すときにウェーハを割った」 |

## 装置

| 言い回し | 台湾のファブでの言い方 | 意味 | 例文 |
|---|---|---|---|
| レシピ | Recipe | 装置がプロセスを処理するときの条件 | 「この工程のレシピは新しい版になった」 |
| PM | PM | 定期的な予防保全 | 「この装置は今日の午後 PM 予定」 |
| ダウン | Down（Down 機） | 装置の故障や停止 | 「エッチング装置がダウンした。EE には連絡済み」 |
| 立ち上げ（復帰） | 復機 | 修理が終わり、生産に戻ること | 「この装置は今夜復帰の見込み」 |
| クオル | Qual | 装置が生産に使えるかを確認すること | 「PM のあとはクオルを通してから製品を流す」 |
| シーズニング | Seasoning | メンテナンス後にダミーを流してチャンバーを安定させること | 「まずダミー 20 枚でシーズニングして」 |
| チャンバー | Chamber | 装置の中で実際に処理を行う部分 | 「このウェーハは B チャンバーで処理された」 |
| アイドル | Idle | 処理するウェーハがなく、装置が空いていること | 「この装置、ずっとアイドルだね」 |
| 号機指定 | 綁機 | ウェーハを特定の装置でしか処理しないように限定すること | 「この層は同じ露光装置に号機指定する」 |
| ロードポート | Load Port | 装置の前面でキャリアを置く台 | 「ロードポートが FOUP の ID を読めない」 |

## システムと流れ

| 言い回し | 台湾のファブでの言い方 | 意味 | 例文 |
|---|---|---|---|
| トラックイン | 進站 | 処理の開始をシステムに登録すること | 「載せたらまずトラックインして」 |
| トラックアウト | 出站 | 処理の完了をシステムに登録すること | 「処理が終わったらトラックアウトを忘れずに」 |
| ホールド | Hold | ロットや装置の生産を止めること | 「このロットは Q タイム超過でホールドされた」 |
| リリース | Release | ホールドを解除し、生産を続けること | 「エンジニアが問題なしと確認したので、リリースしていい」 |
| Q タイム | Q-Time | 二つの工程の間で待てる時間 | 「このロット、Q タイムがもうすぐ切れるから先に流して」 |
| ディスパッチ | 派工 | 装置が次にどのロットを処理するか決めること | 「ディスパッチでこのロットが先頭に来た」 |
| 製品を流す | 跑貨 | 装置で製品ウェーハを処理すること | 「この装置、もう製品を流していい？」 |
| データと実物の不一致 | 帳實不符 | システムの記録と実際の状況が合わないこと | 「システムではトラックアウト済みなのに、ウェーハはまだ装置の中。不一致だ」 |

## 品質と異常

| 言い回し | 台湾のファブでの言い方 | 意味 | 例文 |
|---|---|---|---|
| OOC | OOC | データが管理限界を外れること | 「この点は OOC だから OCAP どおりに」 |
| OOS | OOS | データが規格を外れること | 「膜厚が OOS。MRB を開かないと」 |
| リワーク | Rework | やり直すこと。主にリソグラフィ | 「ADI で落ちたからリワーク」 |
| スクラップ | Scrap | 廃棄すること | 「このウェーハは割れたから、スクラップするしかない」 |
| エクスカーション | Excursion | 突発的な品質異常 | 「昨日の欠陥エクスカーションで 3 ロットが影響を受けた」 |
| MRB | MRB | 不適合品の処置を部門横断で決める会議 | 「このロットは MRB で決める」 |
| マップ | Map | ウェーハマップ | 「このウェーハのマップにスクラッチがないか見て」 |
| パーティクル | Particle | 微小な粒子 | 「このウェーハのパーティクル数が規格オーバー」 |

## エリアと人

| 言い回し | 台湾のファブでの言い方 | 意味 | 例文 |
|---|---|---|---|
| フォト（イエロールーム） | 黃光 | リソグラフィのエリア。照明が黄色いことからこう呼ばれる | 「このロット、フォトで止まってる」 |
| 拡散（炉） | 爐管 | 酸化やアニールなど高温のバッチ式装置のエリア | 「今日は炉のバッチ組みが遅い」 |
| ウェット | Wet | ウェット洗浄とウェットエッチングのエリア | 「まずウェットで洗ってから」 |
| PE、EE、PIE、YE | PE、EE、PIE、YE | プロセス、装置、プロセスインテグレーション、歩留まりのエンジニア | 「これは PIE に判断してもらおう」 |
| 引き継ぎ | 交接 | 勤務交代のときに装置とウェーハの状況を伝えること | 「引き継ぎで、この装置はまだ様子見だとはっきり伝えて」 |
