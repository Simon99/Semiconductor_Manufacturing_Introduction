# 제2부 공정 모듈

팹에는 수백에서 천 개가 넘는 공정이 있지만, 대부분은 몇 가지 기본 '공정 모듈'의 조합입니다. 이 부에서는 각 모듈이 무엇을 하는지, 어떤 장비를 쓰는지, 어떤 수치가 중요한지, 어떤 문제가 자주 생기는지를 차례로 설명합니다.

실제 생산에서 웨이퍼는 이 모듈들을 계속 돌며 증착, 리소그래피, 식각 또는 이온 주입, 세정, 계측을 거쳐 다음 층으로 올라갑니다. 이 책은 루프의 중심인 리소그래피부터 시작합니다.

| 장 | 내용 |
|---|---|
| [제4장 리소그래피](04-lithography/README.md) | 마스크, 감광액, 노광 장비로 회로를 웨이퍼에 '인쇄'하기 |
| [제5장 박막](05-thin-films/README.md) | 열산화, CVD, PVD, ALD, 에피택시 |
| [제6장 식각](06-etching/README.md) | 건식과 습식, 플라즈마, 선택비, 종점 검출 |
| [제7장 이온 주입과 열처리](07-ion-implantation/README.md) | 도즈, 에너지, 어닐링, 열 예산 |
| [제8장 CMP](08-cmp/README.md) | 웨이퍼를 평평하게 연마하기: 슬러리, 디싱, 이로전, 더미 패턴 |
| [제9장 세정과 오염 관리](09-cleaning/README.md) | RCA 세정, Q-타임, 교차 오염 |
| [제10장 금속 배선](10-metallization/README.md) | 콘택, 구리 다마신, Low-k 소재 |
