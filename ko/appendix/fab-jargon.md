# 부록 B 현장 용어

팹의 일상 대화에는 독특한 표현이 많습니다. 예를 들어 "이 로트 Q-타임 곧 끝나니까 먼저 돌려." 업계에 막 들어온 사람은 처음 들으면 어리둥절한 경우가 많습니다.

이 부록에서는 팹에서 자주 듣는 표현을 예문과 함께 정리합니다. 두 번째 열은 대만 팹에서 쓰는 말로, 중국어와 영어 용어가 섞여 쓰입니다. 대만 동료와 일할 때 도움이 됩니다. 표현은 회사마다 다르므로, 여기서는 업계에서 널리 쓰이는 것을 골랐습니다. 정식 정의는 [부록 A 용어집](glossary.md)을 참고하세요.

---

## 웨이퍼와 로트

| 표현 | 대만 팹에서 쓰는 말 | 뜻 | 예문 |
|---|---|---|---|
| 로트 | Lot | 웨이퍼 묶음. 최대 25장 | "이 로트는 오늘 출하야" |
| 투입 | 投片 | 빈 웨이퍼를 생산에 넣는 것 | "이번 달 투입량이 늘었어" |
| 팹 아웃 | Fab Out | 웨이퍼가 전공정을 마치고 팹을 나가는 것 | "이 로트는 다음 주에 팹 아웃 예정이야" |
| 핫 로트 | Hot Lot | 우선 생산하는 로트 | "이건 핫 로트니까 도착하면 바로 돌려" |
| 스플릿 | Split | 한 로트를 그룹으로 나눠 조건을 바꾸는 것 | "이 로트는 세 조건으로 스플릿해" |
| 머지 | Merge | 나눈 웨이퍼를 다시 한 로트로 합치는 것 | "실험 끝나면 머지해서 돌려놔" |
| 뱅크 | Bank | 웨이퍼를 어떤 단계에서 멈춰 대기시키는 것 | "이 로트는 배선 공정 앞에 뱅크해 둬" |
| 재공（WIP） | WIP | 아직 라인 위에 있는 웨이퍼 | "포토 앞에 재공이 너무 쌓였어" |
| 무브 | Move | 일정 기간에 완료한 단계 수. 생산 실적 지표 | "오늘 공장 전체 무브 목표 달성했어?" |
| 모니터 웨이퍼 | 控片 | 장비 상태를 확인하는 테스트용 웨이퍼 | "먼저 모니터 한 장 돌려서 막 두께 확인해" |
| 더미 웨이퍼 | 擋片 | 빈 슬롯을 채우거나 장비를 길들이는 웨이퍼 | "퍼니스 빈 슬롯은 더미로 채워" |
| 웨이퍼 깨짐 | 破片 | 웨이퍼가 깨지는 것 | "로봇이 꺼내다가 웨이퍼를 깼어" |

## 장비

| 표현 | 대만 팹에서 쓰는 말 | 뜻 | 예문 |
|---|---|---|---|
| 레시피 | Recipe | 장비가 공정을 처리할 때의 조건 | "이 단계 레시피는 새 버전으로 바뀌었어" |
| PM | PM | 정기적인 예방 정비 | "이 장비 오늘 오후에 PM 예정이야" |
| 다운 | Down（Down 機） | 장비의 고장이나 정지 | "식각 장비 다운됐어. EE한테 연락했어" |
| 복구 | 復機 | 수리가 끝나 생산에 돌아오는 것 | "이 장비는 오늘 밤 복구 예상이야" |
| 퀄 | Qual | 장비를 생산에 쓸 수 있는지 확인하는 것 | "PM 끝나면 퀄 통과하고 나서 제품 돌려" |
| 시즈닝 | Seasoning | 정비 후 더미를 흘려 챔버를 안정시키는 것 | "먼저 더미 20장으로 시즈닝해" |
| 챔버 | Chamber | 장비 안에서 실제로 처리하는 부분 | "이 웨이퍼는 B 챔버에서 처리됐어" |
| 아이들 | Idle | 처리할 웨이퍼가 없어 장비가 비어 있는 것 | "이 장비 계속 아이들이네" |
| 장비 지정 | 綁機 | 웨이퍼를 특정 장비에서만 처리하도록 한정하는 것 | "이 층은 같은 노광 장비로 지정해" |
| 로드 포트 | Load Port | 장비 앞쪽에서 캐리어를 올려놓는 받침대 | "로드 포트가 FOUP ID를 못 읽어" |

## 시스템과 흐름

| 표현 | 대만 팹에서 쓰는 말 | 뜻 | 예문 |
|---|---|---|---|
| 트랙인 | 進站 | 처리 시작을 시스템에 등록하는 것 | "올렸으면 먼저 트랙인해" |
| 트랙아웃 | 出站 | 처리 완료를 시스템에 등록하는 것 | "끝나면 트랙아웃 잊지 마" |
| 홀드 | Hold | 로트나 장비의 생산을 멈추는 것 | "이 로트 Q-타임 초과로 홀드됐어" |
| 릴리스 | Release | 홀드를 풀고 생산을 계속하는 것 | "엔지니어가 문제없다고 확인했으니 릴리스해도 돼" |
| Q-타임 | Q-Time | 두 단계 사이에서 기다릴 수 있는 시간 | "이 로트 Q-타임 곧 끝나니까 먼저 돌려" |
| 디스패칭 | 派工 | 장비가 다음에 어느 로트를 처리할지 정하는 것 | "디스패칭에서 이 로트가 맨 앞으로 왔어" |
| 제품 돌리기 | 跑貨 | 장비에서 제품 웨이퍼를 처리하는 것 | "이 장비 이제 제품 돌려도 돼?" |
| 장부와 실물 불일치 | 帳實不符 | 시스템 기록과 실제 상황이 맞지 않는 것 | "시스템에서는 트랙아웃됐는데 웨이퍼는 아직 장비 안에 있어. 불일치야" |

## 품질과 이상

| 표현 | 대만 팹에서 쓰는 말 | 뜻 | 예문 |
|---|---|---|---|
| OOC | OOC | 데이터가 관리 한계를 벗어나는 것 | "이 점은 OOC니까 OCAP대로 해" |
| OOS | OOS | 데이터가 규격을 벗어나는 것 | "막 두께 OOS야. MRB 열어야 해" |
| 리워크 | Rework | 다시 하는 것. 주로 리소그래피 | "ADI에서 떨어졌으니 리워크해" |
| 스크랩 | Scrap | 폐기하는 것 | "이 웨이퍼는 깨져서 스크랩할 수밖에 없어" |
| 익스커전 | Excursion | 갑작스러운 품질 이상 | "어제 결함 익스커전으로 세 로트가 영향받았어" |
| MRB | MRB | 부적합품 처리를 여러 부서가 함께 정하는 회의 | "이 로트는 MRB에서 결정해" |
| 맵 | Map | 웨이퍼 맵 | "이 웨이퍼 맵에 스크래치 있는지 봐" |
| 파티클 | Particle | 아주 작은 입자 | "이 웨이퍼 파티클 수가 규격 초과야" |

## 구역과 사람

| 표현 | 대만 팹에서 쓰는 말 | 뜻 | 예문 |
|---|---|---|---|
| 포토（옐로 룸） | 黃光 | 리소그래피 구역. 조명이 노란색이라서 이렇게 부른다 | "이 로트 포토에서 막혀 있어" |
| 확산（퍼니스） | 爐管 | 산화나 어닐링 같은 고온 배치식 장비 구역 | "오늘 퍼니스 배치 묶는 게 늦네" |
| 웻 | Wet | 습식 세정과 습식 식각 구역 | "먼저 웻에서 씻고 와" |
| PE, EE, PIE, YE | PE、EE、PIE、YE | 공정, 설비, 공정 통합, 수율 엔지니어 | "이건 PIE한테 판단해 달라고 하자" |
| 인수인계 | 交接 | 교대 근무 때 장비와 웨이퍼 상황을 넘겨주는 것 | "인수인계할 때 이 장비 아직 지켜보는 중이라고 분명히 전해" |
