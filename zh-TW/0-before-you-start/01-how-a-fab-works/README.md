## 晶圓廠長什麼樣子

晶圓廠（Fab）從外面看像一棟巨大的方形建築，裡面大致分成上中下三層：

- **上層**：巨大的空調與過濾系統，負責把乾淨的空氣送下來
- **中層**：無塵室，機台和晶圓都在這裡
- **下層**：密密麻麻的管線、真空幫浦和化學品供應設備，支援上面的機台

真正生產晶圓的無塵室，只是整棟建築的一部分，其他空間都在「服務」它。

## 無塵室：比手術室還乾淨

晶片上的電路線寬只有幾十奈米甚至更小，一顆比細菌還小的微粒落在晶圓上，就可能讓整顆晶粒報廢。所以晶圓必須在極乾淨的環境中製造。

一般辦公室的空氣中，每立方英尺有數十萬到上百萬顆 0.5 微米以上的微粒；無塵室的關鍵區域則要壓到個位數以下。空氣從天花板的濾網往下吹，穿過有孔的地板被抽走，讓微粒一直被往下帶走。

人是無塵室最大的污染源：皮屑、頭髮、汗水、化妝品都會帶來微粒和污染。所以進無塵室前要穿上全身包覆的無塵衣，再經過風淋室吹掉身上的灰塵。

> [!NOTE]
> **📖 名詞｜無塵室（Cleanroom）**
>
> - **定義**：嚴格控制微粒、溫度、濕度與氣流的生產空間，正式名稱是潔淨室。
> - **現場用法**：「進無塵室前記得換無塵衣」「這區是 Class 1」。
> - **相關名詞**：無塵衣、風淋室、迷你環境
> - **常見混淆**：無塵室不是完全沒有灰塵，而是依每單位體積的微粒數量分級。現場仍常用舊標準的「Class 1」「Class 10」來稱呼等級，數字越小越乾淨。

現代晶圓廠還有一個重要觀念：**迷你環境**。晶圓大部分時間都待在密封的晶圓盒裡，只有在機台內部才會打開，而機台前端本身也是一個小型的超潔淨空間。所以不需要讓整個廠房都達到最高等級，只要晶圓「經過的地方」夠乾淨就好。

## 晶圓怎麼移動：FOUP 與自動搬運

在 300 mm 晶圓廠裡，晶圓裝在一種叫 **FOUP** 的密封盒子裡移動，一盒最多 25 片。裝滿的 FOUP 大約有八公斤重，不適合靠人搬一整天，所以搬運交給自動化系統：

- **天車（OHT）**：在天花板的軌道上行駛，把 FOUP 從一台機台送到另一台。
- **倉儲（Stocker）**：暫時存放還在等待的 FOUP。
- **Load Port**：機台前方放 FOUP 的平台，機台從這裡取出晶圓。

<!-- 圖：天車在天花板軌道上，把 FOUP 放到機台 Load Port 的示意圖 -->

> [!NOTE]
> **📖 名詞｜FOUP（Front Opening Unified Pod，前開式晶圓傳送盒）**
>
> - **定義**：300 mm 晶圓廠用來裝載、保護與搬運晶圓的密封盒，最多裝 25 片。
> - **現場用法**：「那個 FOUP 還在 Stocker 裡，要先叫下來。」
> - **相關名詞**：Lot、OHT、Stocker、Load Port
> - **常見混淆**：FOUP 是「盒子」，Lot 是「一批晶圓」。通常一個 Lot 裝在一個 FOUP 裡，但兩者不是同一件事，晶圓也可能換盒。

## 機台：工廠的主角

晶圓廠裡有上千台機台，通常依照製程類型分區擺放，例如黃光區（微影）、蝕刻區、爐管區、薄膜區、離子佈植區、CMP 區、濕式清洗區和量測區。

機台大致分成兩種：

- **單片式**：一次處理一片晶圓，例如曝光機、大部分的蝕刻機。
- **批次式**：一次處理很多片晶圓，例如爐管，一次可以放進上百片。

機台不會一直在生產。除了正常運轉和待機，它還會定期停下來做**保養**（PM，Preventive Maintenance），也可能突然**故障**（現場叫「Down 機」）。

> [!TIP]
> **🔧 Know-how｜保養完的機台不能馬上跑產品**
>
> - **情境**：機台完成保養，零件換新、腔體清潔過。
> - **做法**：先跑測試用的晶圓，檢查微粒、膜厚、蝕刻率等是否正常，確認合格後才開放生產。這個確認過程現場常叫「Qual」。
> - **為什麼**：保養會改變機台內部的狀態，新零件和剛清潔過的腔體不一定馬上穩定。
> - **沒做會怎樣**：如果機台其實有問題，第一批跑進去的產品晶圓可能整批報廢。
> - **相關章節**：[第 6 章 蝕刻](../../2-process-modules/06-etching/README.md)、[第 15 章 量測與檢測](../../4-yield-and-quality/15-metrology/README.md)

## 工廠的血液：廠務系統

機台要運轉，需要大量穩定的資源供應，這些由**廠務**負責：

- **超純水**：清洗晶圓用，純度遠高於飲用水，用量非常大。
- **特殊氣體與化學品**：很多具有毒性、腐蝕性或易燃性，需要專門的供應與偵測系統。
- **電力**：一次極短暫的電壓不穩，就可能讓正在加工的晶圓報廢。
- **排氣與廢水處理**：處理製程產生的廢氣與廢液。
- **溫濕度與振動控制**：曝光機等精密機台對環境變化非常敏感。

## 誰在晶圓廠裡工作

晶圓廠 24 小時、全年無休地運轉，技術員和部分工程師需要輪班。常見的職務如下：

| 職務 | 主要工作 |
|---|---|
| 製程工程師（PE） | 負責某一類製程的 Recipe 與品質，處理製程異常 |
| 設備工程師（EE） | 負責機台的保養、維修與穩定運作 |
| 製程整合工程師（PIE） | 從整條流程看產品，協調各製程，確保電性與良率達標 |
| 良率工程師（YE） | 分析良率與缺陷資料，找出良率損失的原因 |
| 製造部（MFG） | 安排生產、操作與監控機台，讓晶圓準時產出 |
| 廠務工程師 | 維持水、電、氣體、化學品與無塵室環境的穩定 |
| 品保工程師（QA） | 負責品質系統、可靠度驗證與客戶品質問題 |
| CIM 工程師 | 開發與維護工廠的自動化與資訊系統 |

## 工廠怎麼衡量表現

晶圓廠最常看的三個指標：

- **生產週期（Cycle Time）**：一批晶圓從投片到完成要花多久。
- **良率（Yield）**：做出來的晶片有多少比例是好的。
- **產出（Output）**：一段時間內完成多少片晶圓。

還有一個重要概念是**在製品**（WIP，Work in Process），也就是還在生產線上、尚未完成的晶圓。WIP 越多，每片晶圓排隊等機台的時間就越長，就像車越多，高速公路越塞。

這麼多晶圓、步驟和機台，不可能靠人記。工廠的資訊系統會記錄每一片晶圓走過的每一站、用了哪台機台、量到什麼數據，這部分在[第 23 章](../../6-beyond-the-fab/23-fab-systems/README.md)介紹。

> [!TIP]
> **🔧 Know-how｜急件越多，工廠越慢**
>
> - **情境**：有些晶圓被設定為急件（Hot Lot），在每一站都可以優先使用機台。
> - **做法**：工廠會嚴格限制急件的數量。
> - **為什麼**：每一批急件插隊，其他晶圓就得多等一下；批次式機台還可能為了急件不等湊滿就開機，降低效率。
> - **沒做會怎樣**：如果每批都是急件，就等於沒有急件，整座工廠的生產週期反而變長。
> - **相關章節**：[第 23 章 工廠如何被系統管理](../../6-beyond-the-fab/23-fab-systems/README.md)

## 本章重點

1. 晶圓廠分成上中下三層，真正生產的無塵室需要整棟建築的支援。
2. 無塵室嚴格控制微粒，而人是最大的污染源。
3. 晶圓裝在 FOUP 裡，由天車和倉儲自動搬運。
4. 機台分成單片式與批次式，保養後必須確認合格才能生產。
5. 生產週期、良率和產出是工廠最重要的三個指標，WIP 越多生產週期越長。
