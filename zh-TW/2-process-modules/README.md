# 第 2 部　製程模組

晶圓廠裡的步驟多達數百到上千個，但大部分都是由幾種基本的「製程模組」反覆組合而成。這一部逐一介紹每個模組：它在做什麼、用什麼機台、要看哪些指標、常出什麼問題。

實際生產時，晶圓會在這些模組之間反覆循環：鋪上薄膜、微影、蝕刻或佈植、清洗、量測，然後再往上做下一層。本書從微影開始介紹，因為它是整個循環的核心。

| 章節 | 你會讀到 |
|---|---|
| [第 4 章　微影](04-lithography/README.md) | 光罩、光阻與曝光機，把電路圖「印」到晶圓上 |
| [第 5 章　薄膜](05-thin-films/README.md) | 熱氧化、CVD、PVD、ALD 與磊晶 |
| [第 6 章　蝕刻](06-etching/README.md) | 乾蝕刻與濕蝕刻、電漿、選擇比與終點偵測 |
| [第 7 章　離子佈植與熱處理](07-ion-implantation/README.md) | 劑量、能量、退火與熱預算 |
| [第 8 章　CMP](08-cmp/README.md) | 把晶圓磨平：研磨液、碟陷、侵蝕與虛擬填充 |
| [第 9 章　清洗與污染控制](09-cleaning/README.md) | RCA 清洗、Q-Time 與交叉污染 |
| [第 10 章　金屬化](10-metallization/README.md) | 接觸窗、銅的大馬士革製程與低介電常數材料 |
