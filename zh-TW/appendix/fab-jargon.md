# 附錄 B　現場行話

晶圓廠的日常溝通，常常是中文夾雜英文術語，例如「這批 Q-Time 快到了，先跑它」。剛入行的人第一次聽到，常常一頭霧水。

本附錄收錄晶圓廠裡常聽到的說法，並附上例句。各公司的習慣用語不完全相同，這裡整理的是業界普遍的講法。正式的術語定義請見[附錄 A 術語總表](glossary.md)。

---

## 晶圓與批次

| 行話 | 意思 | 例句 |
|---|---|---|
| Lot | 一批晶圓，最多 25 片 | 「這個 Lot 今天要出貨。」 |
| 投片（Wafer Start） | 把空白晶圓投入生產 | 「這個月的投片量增加了。」 |
| Fab Out | 晶圓完成前段製程，離開晶圓廠 | 「這批預計下週 Fab Out。」 |
| Hot Lot | 優先生產的急件 | 「這批是 Hot Lot，到站先跑。」 |
| Split | 把一批晶圓分成幾組，做不同條件 | 「這批要 Split 成三組條件。」 |
| Merge | 把分開的晶圓合回同一批 | 「實驗做完就 Merge 回去。」 |
| Bank | 讓晶圓暫停在某個步驟等待 | 「這批先 Bank 在金屬層前面。」 |
| WIP | 還在生產線上的晶圓 | 「黃光前面的 WIP 堆太多了。」 |
| Move | 一段時間內晶圓完成的步驟數，用來衡量產出 | 「今天全廠的 Move 有達標嗎？」 |
| 控片 | 用來檢查機台狀態的測試晶圓（Monitor Wafer） | 「先跑一片控片確認膜厚。」 |
| 擋片 | 用來填補空位或調整機台的晶圓（Dummy Wafer） | 「爐管空位記得補擋片。」 |
| 破片 | 晶圓破裂 | 「機械手臂取片時破片了。」 |

## 機台

| 行話 | 意思 | 例句 |
|---|---|---|
| Recipe | 機台執行製程用的參數組合 | 「這道的 Recipe 換新版本了。」 |
| PM | 定期保養 | 「這台今天下午排 PM。」 |
| Down（Down 機） | 機台故障或停用 | 「蝕刻機 Down 了，已經通知 EE。」 |
| 復機 | 機台修好、恢復生產 | 「這台預計晚上復機。」 |
| Qual | 確認機台狀態合格的驗證 | 「PM 完要先 Qual 過才能跑貨。」 |
| Seasoning | 保養後先跑擋片，讓腔體穩定 | 「先 Season 二十片擋片。」 |
| Chamber | 機台中實際做製程的腔體 | 「這片是在 B 腔做的。」 |
| Idle | 機台閒置、沒有晶圓可跑 | 「這台 Idle 很久了。」 |
| 綁機（Dedication） | 指定晶圓只能在特定機台上做 | 「這層要綁同一台曝光機。」 |
| Load Port | 機台前方放晶圓盒的平台 | 「Load Port 讀不到 FOUP 的編號。」 |

## 系統與流程

| 行話 | 意思 | 例句 |
|---|---|---|
| 進站（Track-in） | 在系統上登記開始加工 | 「貨放上去記得先進站。」 |
| 出站（Track-out） | 在系統上登記完成加工 | 「機台跑完了，記得出站。」 |
| Hold | 暫停晶圓或機台的生產 | 「這批被 Hold 了，原因是 Q-Time 超過。」 |
| Release | 解除 Hold，放行繼續生產 | 「工程師確認沒問題，可以 Release。」 |
| Q-Time | 兩站之間允許等待的時間 | 「這批 Q-Time 快到了，先跑它。」 |
| 派工 | 決定機台下一批要跑哪一批晶圓 | 「派工系統把這批排在最前面。」 |
| 跑貨 | 讓產品晶圓在機台上生產 | 「這台現在可以跑貨了嗎？」 |
| 帳實不符 | 系統紀錄和實際狀況不一致 | 「系統顯示已出站，晶圓卻還在機台裡，帳實不符。」 |

## 品質與異常

| 行話 | 意思 | 例句 |
|---|---|---|
| OOC | 數據超出管制界限 | 「這點 OOC 了，照 OCAP 處理。」 |
| OOS | 數據超出規格 | 「膜厚 OOS，要開 MRB。」 |
| Rework | 重新製作，主要用在微影 | 「ADI 沒過，要 Rework。」 |
| Scrap | 報廢 | 「這片破片了，只能 Scrap。」 |
| Excursion | 突發的品質異常事件 | 「昨天那次缺陷的 Excursion 影響了三批。」 |
| MRB | 跨部門判定不合格品處置的會議 | 「這批要開 MRB 決定。」 |
| Map | 晶圓圖 | 「看一下這片的 Map 有沒有刮痕。」 |
| Particle | 微粒 | 「這片的 Particle 數超標。」 |

## 區域與人

| 行話 | 意思 | 例句 |
|---|---|---|
| 黃光 | 微影區，因照明是黃色而得名 | 「這批卡在黃光。」 |
| 爐管 | 氧化、退火等批次式高溫機台的區域 | 「爐管今天組批比較慢。」 |
| Wet | 濕式清洗與濕蝕刻區 | 「這道要先到 Wet 洗一下。」 |
| PE、EE、PIE、YE | 製程、設備、製程整合、良率工程師 | 「這個問題要找 PIE 判斷。」 |
| 交接 | 換班時說明機台與晶圓的狀況 | 「交接時要講清楚這台還在觀察。」 |
